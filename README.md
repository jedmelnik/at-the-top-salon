# At The Top Salon

Modern rebuild of [atthetopsalon.com](https://atthetopsalon.com/) - a Mill Valley gallery / salon - for Jed Melnik.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui

## Local development

```bash
npm install
npm run dev -- --port 43171
```

Open [http://127.0.0.1:43171](http://127.0.0.1:43171).

## Scripts

- `npm run dev` - development server
- `npm run build` - production build
- `npm run start` - serve production build
- `npm run lint` - ESLint

## Source facts

Contact, booking, team, services, and product lines are taken from the live WordPress site. Brand mark is the original triangle + AT THE TOP lockup (outdated "Ten East" address line removed from the file; current address is 219 E. Blithedale Ave.).
